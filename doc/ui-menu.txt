==============================================================================
1. 安装                                                     *ui-menu-install*

>lua
  require("ui_menu").setup({ replace_select = true })
<
`replace_select` 默认 false，只导出 `select()`；true 才接管 |vim.ui.select()|。
需要在其它插件的 config 调用 vim.ui.select 之前 setup。

==============================================================================
2. 配置                                                     *ui-menu-config*

  width (number)          最大宽度，默认 64
  min_width (number)      最小宽度，默认 30
  max_height (number)     最多显示行数，默认 14
  border (string)         边框样式，默认 "rounded"
  tick (number)           动画帧间隔 ms，默认 90
  replace_select (bool)   是否接管 vim.ui.select，默认 false
  should_replace (fun)    返回 false 时交给原实现

==============================================================================
3. API                                                        *ui-menu-api*

  select(items, opts, on_choice)      同 vim.ui.select，返回 boolean
  spinner(frames?)                    返回 fun(frame?, base?)
  frames                              默认动画帧
  config                              当前配置
  original_select                     接管前的 vim.ui.select

opts.tick = true|number 开启动画，format_item(item, frame)。
opts.position = "center" 固定屏幕居中，不跟随光标。
opts.on_tab = fun() 菜单里按 <Tab> 时关闭菜单并调用它。
format_item 的第二返回值 virt_text 挂到行尾。
结构化条目支持 name/text/label + icon/icon_hl/name_hl。
