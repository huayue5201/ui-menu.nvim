==============================================================================
1. Installation                                             *ui-menu-install*

>lua
  require("ui_menu").setup({ replace_select = true })
<
`replace_select` defaults to false, which only exports `select()`; set it to
true to take over |vim.ui.select()|. Setup must happen before other plugins'
config calls vim.ui.select.

==============================================================================
2. Configuration                                            *ui-menu-config*

  width (number)          maximum width, default 64
  min_width (number)      minimum width, default 30
  max_height (number)     maximum visible rows, default 14
  border (string)         border style, default "rounded"
  tick (number)           animation frame interval in ms, default 90
  replace_select (bool)   take over vim.ui.select, default false
  should_replace (fun)    return false to fall back to the original implementation

==============================================================================
3. API                                                        *ui-menu-api*

  select(items, opts, on_choice)      same as vim.ui.select, returns boolean
  spinner(frames?)                    returns fun(frame?, base?)
  frames                              default animation frames
  config                              current configuration
  original_select                     vim.ui.select before the takeover

opts.tick = true|number enables animation, format_item(item, frame).
opts.position = "center" pins to screen center instead of following the cursor.
opts.on_tab = fun() closes the menu and calls it when <Tab> is pressed.
The second return value of format_item, virt_text, is shown at end of line.
Structured items support name/text/label + icon/icon_hl/name_hl.
